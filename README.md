# Grabba privacy and support

This public repository contains the privacy policy and security documentation
for the **Grabba** Chrome extension. Grabba processes tab recordings and video
edits locally and does not upload recorded content.

- [Privacy policy](PRIVACY.md)
- [Security and privacy design](SECURITY.md)
- [Request support or report a non-sensitive issue](https://github.com/affernan/Grabba-privacy/issues)

Do not attach real recordings, credentials, personal data, or confidential tab
content to a public issue.
